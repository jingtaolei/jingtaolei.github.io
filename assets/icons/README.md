# JL favicon

The source is `../../favicon.svg`: a transparent JL lettermark using Iowan Old Style Italic, the serif family used in the website. Letter outlines are exported as paths, so no font file or installed font is required by the browser. Fine strokes receive a .35px reinforcement at the 64px source size. There is no box, border, or background in the SVG or browser PNGs.

Plant green (#425e46) is used on light browser themes and pale green (#dfe7d5) on dark themes. SVG adapts to prefers-color-scheme; light/dark 32px PNGs provide the browser raster versions; unused 16px exports are archived. ICO contains 16px, 32px and 48px sizes. The Apple touch export is 180px on an opaque paper field for the operating system's own icon mask. The unused transparent 512px master is archived.

Public pages use content-addressed icon URLs. The original size/theme preview is archived with the former design notes outside the website directory.
