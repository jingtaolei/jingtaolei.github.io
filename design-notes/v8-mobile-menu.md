# 第八版：移动菜单的连续过渡

修改前完整备份：`../ui-backups/v7-material-and-cache-2026-10-14`。第七版已由用户上传 GitHub；本次仅生成本地可审阅版本，等待用户确认后再更新远端。

原菜单通过 `display:none` / `display:grid` 切换，面板没有可插值的展开收起过程。现在移动菜单保持网格布局，以透明度、轻微纵向展开和位移形成连续的 360–420ms 过渡。文字按行间隔 30ms 出现，加号旋转采用同一缓动。退出时立刻阻止点击与键盘进入，面板继续完成淡出。快速再次点击时，CSS 从当前过渡进度反向，不会重新从头出现。保留原玻璃材质、字形、配色和两列导航。

没有增加循环、帧回调、动态模糊或布局测量。沿用系统减少动态偏好。关闭的移动菜单使用 `inert`，Escape 返回菜单按钮；点击章节或面板外部收起。跨越桌面断点时清理展开状态，桌面导航恢复正常键盘可达性。首页顶栏与画面融合、滚动后出现玻璃底的行为保持原样。

修改源文件后已经重新生成内容指纹资源；历史资源继续保留。

验证：320px / 390px 竖屏无横向溢出；展开完成后面板和全部链接透明度均为 1，变换回到单位矩阵；收起过程中面板仍可见并逐渐淡出，同时已不可交互。快速反向展开连续恢复。Escape 关闭并返回按钮，点击面板外与章节导航关闭正常；820px 桌面断点清理展开状态且导航不再 inert。隐私页菜单同样正常。浏览器无脚本错误或警告，生成资源检查通过。与备份相比，页面正文、简历、图标及其他交互脚本保持一致。效果截图：`../ui-previews/v8-mobile-menu.png`。

竖屏菜单细化：导航项按文字宽度占位，保留至少 44px 的点击尺寸；小点与悬停横条放在对应文字下方居中，距条目底部 4px，避免原来的行首标记。桌面标记与菜单展开过渡沿用原样。
