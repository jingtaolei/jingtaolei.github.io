# 第六版：图示关注反馈与数学基底映射

2026-10-13。第五版完整备份在 `../ui-backups/v5-texture-and-notes-2026-10-13`。本次为同一版的局部精修，不额外创建细小快照。

首页取消固定标签衬底，恢复原有植物色文字 #61755a 与轴线 #687f67。原生 SVG title 提示移除，使用 aria-label 与 desc 保留读屏说明。说明框和全站正文排版保持原样。

鼠标进入首页图示时，只有图示背后的局部羽化层逐渐显现，使用小范围 10px 背景模糊与半透明纸色，没有矩形实色底。根据预览反馈，羽化范围向上、左右与底部略微扩展，覆盖图示外缘；中心清晰区域扩到 48%，外缘在 78% 渐隐。图示轻微放大 2.5%，三段标签平滑放大 16% 并微量增厚，时间标记与关键轴线稍微突出，过渡 .6 秒。移开后各属性平滑恢复。键盘聚焦有相同反馈，鼠标点击不会把关注状态永久锁住。静止状态保留原有质感与配色。

About 改为宽幅基底映射，桌面最大 420px、手机最大 360px。左侧是静态正交基底与单位格，中央的信号线向右传递，右侧方格在固定原点上剪切为斜格并复原；对应应用数学基础与表征研究。只使用小型 SVG 的 CSS 变换，离屏、后台与减少动态偏好暂停或静态展示。

Contact 保留 .45 秒交叉淡化。鼠标移出时暂停运动层并保留当时相位，淡回完整静态图；重新进入时从保留相位继续，避免直接撤销动画导致重置。

精修验证：实际鼠标悬停时图示虚化层透明度到达 1、标签缩放到 1.16、轴线宽度到 1.4；鼠标移出后进入渐隐并回到原态，点击不会锁住反馈。About 桌面为 420px，映射与剪切动画正常运行；320、390、1440 像素布局没有横向溢出。

## JL 网页图标

透明背景上的 JL 斜体字母组合，沿用正文 Iowan Old Style 的字族。使用笔画粗细与曲线延伸形成书写感，去除原先的底板和切角造型。两字已转成矢量轮廓，浏览器不需要安装字体；为小尺寸细笔画做了微量加强。

浅色标签页使用植物绿，深色标签页使用浅绿，SVG 自动响应主题，PNG 提供两套颜色。提供 16/32px PNG、16/32/48px ICO 和手机收藏图标，页面缓存版本更新为 jl-2。预览已检查 16、32、48px 以及浅、深两种底色。
