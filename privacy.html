Privacy

Last updated: October 14, 2026

This is a personal academic website. It does not provide user accounts, advertising, e-commerce, or forms that ask visitors to submit personal information.

Cloudflare analytics

This site records anonymous website statistics through a Cloudflare Pages collection endpoint and Workers Analytics Engine. Each event is sent to one verified endpoint; an existing Worker endpoint can serve as a connection fallback and uses the same dataset.

These statistics include page views, visits to major sections, and clicks on the CV, GitHub profile, project code, Publications navigation, and contact links.

New page loads no longer load the separate Cloudflare Web Analytics beacon. Previously collected Web Analytics aggregates remain available to the site owner during Cloudflare's retention window.

For these anonymous events, the site may store the event type, page path, referring website host, approximate country, region and city, timezone, a coarse device class, and the event time. Approximate location is derived by Cloudflare from the incoming network request. The site does not store the visitor's IP address, precise coordinates, postal code, full user-agent string, cookies, persistent visitor IDs, session IDs, email addresses, or browser fingerprints for this analytics system. Events are therefore not linked into individual visitor profiles or cross-visit histories. Unsent events may be held only in the current page’s memory for up to two minutes while a collection connection is unavailable; they are not saved in browser storage. Event times reflect when the collector receives them.

The site does not use Google Analytics, Microsoft Clarity, session recording, advertising trackers, or analytics cookies.
