Privacy

Last updated: September 5, 2026

This is a personal academic website. It does not provide user accounts, advertising, e-commerce, or forms that ask visitors to submit personal information.

Cloudflare analytics

This site uses Cloudflare Web Analytics for aggregate traffic and website performance measurement. Cloudflare states that Web Analytics does not use cookies to collect usage metrics and is designed without cross-site tracking of individual visitors.

The site also records a small set of anonymous interaction events through a Cloudflare Worker and Workers Analytics Engine. These events include page views, visits to major sections, and clicks on the CV, GitHub profile, project code, Publications navigation, and contact links.

For these anonymous events, the site may store the event type, page path, referring website host, approximate country, region and city, timezone, a coarse device class, and the event time. Approximate location is derived by Cloudflare from the incoming network request. The site does not store the visitor's IP address, precise coordinates, postal code, full user-agent string, cookies, persistent visitor IDs, session IDs, email addresses, or browser fingerprints for this analytics system. Events are therefore not linked into individual visitor profiles or cross-visit histories.

The site does not use Google Analytics, Microsoft Clarity, session recording, advertising trackers, or analytics cookies.
